# Джим и Майк: Битва за пульт

Игра для двоих: на одной клавиатуре или онлайн по коду комнаты.

## Запуск на компьютере
```
npm install
npm start
```
Открой http://localhost:3000. Для онлайна создай комнату в одном окне и войди по коду в другом.

## Деплой на Render
1. Создай репозиторий на GitHub и загрузи туда все файлы из этой папки (`server.js`, `package.json`, `render.yaml`, папка `public/`).
2. На render.com: **New → Web Service** → выбери репозиторий.
3. Настройки: Runtime **Node**, Build Command `npm install`, Start Command `npm start`, тариф Free.
   (Если выберешь **New → Blueprint**, всё подхватится из `render.yaml`.)
4. После деплоя открой ссылку вида `https://jim-and-mike.onrender.com`, создай комнату и отправь код другу.

Бесплатный тариф «засыпает» после простоя — первая загрузка может занять около минуты.

## Совместимость со старыми ПК (Windows 7 32-bit, Яндекс.Браузер)
- Клиентский код (`public/game.js`) собран под Chromium 58+, поэтому работает и в последней версии Яндекс.Браузера для Win 7 (Chromium ~108).
- three.js лежит в `public/three.min.js` (не с CDN) — меньше зависимостей от HTTPS-сертификатов на старой системе.
- Исходник игры — `src/game.src.js`. Если меняешь его, пересобери: `npm install && npm run build` и загрузи обновлённый `public/game.js` в репозиторий. Render собирать ничего не нужно.
- Если на Win 7 нет картинки: включи «Аппаратное ускорение» в настройках браузера и обнови драйвер видеокарты (нужен WebGL).
- Если браузер ругается на сертификат сайта — установи обновления Windows 7 или корневой сертификат ISRG Root X1.
